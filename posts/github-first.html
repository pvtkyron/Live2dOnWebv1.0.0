Why this storefront is GitHub-first

An architecture note on keeping Project Rev pages, assets, posts and product data independent from Blogfa.

The design rule is simple: if Blogfa disappears tomorrow, the store should still work.

The repository owns the house

HTML pages, CSS, scripts, product data, the Live2D integration, sitemap, robots rules and compatibility templates all live in GitHub.

Blogfa becomes a doorway

The provided Blogfa template can point toward the canonical storefront and expose standard crawlable links, but it is not the database, renderer, or source of truth.

Why that matters

You can move hosts, change the CMS, add a domain, or publish through another static host without rewriting the product catalog. The repository remains the portable source.

And the mascot?

The existing Live2D code stays in the same repository, so the character travels with the storefront instead of becoming an external dependency.
