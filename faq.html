FAQ / BEFORE YOU MESSAGE

Answers without the treasure hunt.

The boring questions matter. Hosting, buying, versions, support and what the animated menace in the corner is doing here.

Where does Project Rev live?

The durable site source lives on GitHub and the static storefront is designed to work directly on GitHub Pages.

Does the storefront depend on Blogfa?

No. Blogfa can act as a public shell, while the actual market pages and assets remain GitHub-fed and independently addressable.

Where do I buy or ask about availability?

Use the official Telegram lane at @project_rev. Confirm the current offer, requirements and terms before paying.

Why are commercial details not frozen forever on the page?

Because versions, bundles and availability can move. The site explains what each lane is for; the official channel confirms what is current.

Why is there a Live2D character?

Because a useful site is allowed to have a personality 😌 The mascot is a separate presentation layer and the core content still works without it.

Can search engines crawl the site properly?

Yes. Project Rev uses static pages, normal links, canonical URLs, crawler rules and a real XML sitemap.

What if I am not sure which product lane fits?

Start with the job you need done. The shop explains the lanes, and the journal gives more context before you choose.
